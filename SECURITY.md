# Security Policy

## Reporting Security Issues

The MetalLB maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/metallb/metallb/security/advisories/new) form.

For more details, see the [MetalLB security policy](https://github.com/metallb/metallb/blob/main/SECURITY.md).
